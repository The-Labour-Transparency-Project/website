# How to use the Code

The Code is a shared standard, not a single platform. It can be adopted gradually through industry assurance programmes, certification schemes, buyer requirements or export-supply-chain standards.

## What adoption should demonstrate

Participating organisations should be able to show, in a proportionate way:

- workforce traceability to a responsible employer, agreement and worksite;
- declared labour supply relationships, including subcontracting;
- verifiable identity, right-to-work, time and payroll records; and
- durable records that support appropriate assurance and investigation.

## A practical adoption pattern

1. Assess current records and contractor visibility.
2. Identify gaps against the ten rules.
3. Agree minimum evidence and data-sharing arrangements.
4. Test assurance using a defined supply-chain pilot.
5. Publish findings, improve the standard and expand participation.

## Keep the standard alive

The Code should be maintained through a transparent process: clear ownership, version numbers, consultation for material changes, implementation guidance and a public changelog.
