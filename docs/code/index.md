# Labour Transparency Code

The Labour Transparency Code establishes minimum expectations for visibility and accountability in agricultural and horticultural labour supply chains.

Its purpose is to help supply chains become transparent, traceable and accountable in ways that protect workers, support compliant businesses and strengthen trust in New Zealand agricultural exports.

The Code is the first layer of the wider [Labour Transparency Framework](../framework.md): it sets the outcomes, while the framework describes the infrastructure, assurance and adoption layers needed to make those outcomes practical.

## Principles

### Transparency

Relevant labour supply relationships should be visible to the relevant supply-chain participants. [Labour Supply Chains Are Not Linear](../articles/03-labour-supply-chains-are-not-linear.md) explains why visibility must include the relationships around a worker, not only the immediate employer.

### Accountability

Every worker should be clearly linked to a legally responsible employer. See [Labour Opacity Is a Structural Risk](../articles/02-labour-opacity-as-structural-risk.md) for why unclear responsibility expands risk.

### Attribution

Labour participation should be traceable to specific worksites and supply-chain actors. [Product Traceability Is Mature. Workforce Traceability Is Not.](../articles/01-product-traceability-and-workforce-traceability.md) sets out the central proposition behind this rule.

### Proportional assurance

Transparent systems should support risk-based assurance and avoid unnecessary burden on compliant operators. [Assurance Must Be Proportionate](../articles/09-proportionate-assurance.md) develops this principle in more detail.

### Technology neutrality

The Code defines outcomes. It does not mandate a platform, vendor or technical architecture.

## Scope

The Code is intended for growers and producers, labour providers and contractors, labour-hire businesses, and—where relevant—processors and exporters participating in agricultural and horticultural supply chains.
