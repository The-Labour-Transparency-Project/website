# Implementation

The appropriate path is staged: begin with a shared standard, test practical records and assurance arrangements with a small coalition, then expand only when the approach demonstrates value.

## A possible sequence

### 1. Establish a founding coalition

Bring together industry bodies, grower representatives, labour providers, workers' representatives, infrastructure providers and policy observers. The purpose is to test—not impose—the model.

### 2. Refine the Code

Translate the ten rules into implementable evidence expectations, definitions, roles and a versioned change process.

### 3. Pilot workforce traceability

Use a limited number of real supply-chain participants to test how worker–employer, provider and worksite relationships can be verified across existing systems.

### 4. Test proportional assurance

Design assurance that uses transparent records to focus effort where risk is higher, while recognising operators that can demonstrate sound systems.

### 5. Develop the ecosystem

Create clear conformance expectations for auditors, technology providers, worker-reporting channels and investigation providers. Governance can become more independent as the infrastructure and ecosystem mature.

## Design principles

| Principle | In practice |
| --- | --- |
| Worker-centred | Do not expose personal records publicly; enable trustworthy evidence and channels for worker voice. |
| Technology-neutral | Specify outcomes and interoperable information, rather than one mandated platform. |
| Proportionate | Match assurance effort to demonstrated risk and capability. |
| Practical | Build from existing business processes wherever possible. |
| Governable | Maintain clear ownership, versioning, auditability and escalation pathways. |

## Questions to resolve in a pilot

- What minimum data and evidence are actually necessary for attributable labour participation?
- Who can access which information, for which purpose, and under what authority?
- How should records be verified, corrected and retained?
- What interoperability profile is realistic across small and large operators?
- How can worker voice and complaint channels operate safely alongside formal records?
